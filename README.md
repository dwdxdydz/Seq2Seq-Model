# Sequence-to-Sequence Translation Model

A PyTorch inference utility demonstrating greedy decoding for an encoder-decoder sequence-to-sequence model.

## What it demonstrates

- Source-token preprocessing and vocabulary lookup
- Tensor construction for model inference
- Autoregressive decoder generation
- EOS-based early stopping
- Conversion from predicted token IDs back to words

## Tech Stack

**Python · PyTorch · Seq2Seq · Neural Machine Translation**

## Project Status

This repository contains the inference component of a Seq2Seq experiment. The training model, tokenizer implementation, and vocabulary construction are external to the current file, so it should be presented as an inference utility rather than as a complete end-to-end training project.
